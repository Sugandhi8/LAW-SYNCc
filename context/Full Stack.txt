# Legal Dictionary App — Full Stack Project Documentation

## 1. Project Overview

**Legal Dictionary App** is a full-stack web application that helps users understand legal terms in simple language. Users can search legal terms, view definitions, examples, related laws, save bookmarks, view search history, take quizzes, and compare legal terms.

### Main Goal
To make legal terminology easier to understand for students, common users, and anyone who wants quick access to legal information.

---

## 2. Objectives

- Provide a searchable legal dictionary.
- Explain complex legal terms in simple language.
- Display examples and related laws/sections.
- Allow users to bookmark important terms.
- Maintain user search history.
- Provide quizzes for learning.
- Compare two legal terms.
- Support text-to-speech / voice search.
- Provide secure user authentication.
- Create an admin-friendly system for managing legal terms.

# 10. Authentication Flow

```text
User
 │
 ├── Register
 │       │
 │       ▼
 │   Backend validates data
 │       │
 │       ▼
 │   Password hashed using bcrypt
 │       │
 │       ▼
 │   User stored in MongoDB
 │
 └── Login
         │
         ▼
   Backend verifies password
         │
         ▼
      JWT Token
         │
         ▼
   Frontend stores auth state
         │
         ▼
 Protected API requests
```

# 11. Search Flow

```text
User enters legal term
        ↓
React SearchBar
        ↓
Axios API request
        ↓
GET /api/terms?search=...
        ↓
Express Route
        ↓
Term Controller
        ↓
MongoDB Search
        ↓
Matching Terms
        ↓
JSON Response
        ↓
React displays Term Cards
```

# 12. Environment Variables

```env

MONGO_URI=mongodb://localhost:27017/legal_dictionary
```

Optional:

```env
OPENAI_API_KEY=your_api_key
EMAIL_USER=your_email
EMAIL_PASS=your_password
```

### Frontend `.env`

```env
VITE_API_URL=http://localhost:5000/api
```

Do not upload `.env` files or secret API keys to GitHub.

- Password hashing using bcrypt.
- JWT authentication.
- Protected routes.
